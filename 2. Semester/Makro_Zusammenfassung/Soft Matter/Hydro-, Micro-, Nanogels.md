## Network architecture
- network topology influences properties
- architecture: spatial arrangement of polymer chains and crosslinks
	- homogeneous network
	- heterogeneous network
	- gradient network
	- double network
	- interpenetrating polymer network (IPN)
	- composite network
### (Semi-)interpenetrating Networks ((Semi-)IPNs)
IPNs:
- combining independently crosslinked networks
- synergistic integration of complementary properties
	- improved mechanical strength, toughness, swelling controll, multifunctionality
Semi-IPNs:
- incorporating linear polymer into crosslinked network
- combination of functionalities without altering primary network structure & synthesis
![[IPN.png]]

- employ movable crosslinks that redistribute stress during deformation
	- exceptionally strechable & fatigue-resistant hydrogel networks
